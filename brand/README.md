# BodySmith identity

Standalone assets derived from the approved B + S brand board using Image Gen, then resized and optimized for software use. The exercise media is unchanged.

- `mark.png`: transparent icon master, header and onboarding.
- `wordmark-dark.webp`: horizontal wordmark, dark backgrounds.
- `mark-light.png`, `wordmark-light.webp`: light-background fallback assets.
- `favicon-16.png`, `favicon-32.png`: small browser icons.
- `maskable-512.png`: Android maskable artwork inside the central safe area.
- `apple-touch-icon.png`: 180px Apple touch icon.
- Root `icon-192.png` and `icon-512.png`: standard PWA icons.
- `icons/`: Tabler outline icons, MIT license included. Vendored so workouts need no icon CDN.

The mark and wordmark are optimized raster assets, not hand-traced vectors. Keep the transparent masters for future professional vector refinement.
