# Exercise media

BodySmith uses anatomy illustrations generated for this app: grayscale athletes/equipment, warm muscle highlights, and two equal start/end panels. WebP heroes are 1400 × 700; separate 256 × 256 thumbnails keep library browsing light. Images are simplified instructional references, not personalized form assessment. Setup and execution text explain the movement and equipment-specific precautions.

The service worker caches viewed images and preloads only current/next workout heroes plus the active day's thumbnails. Catalog metadata lives in `data/exercises.json`; historical legacy slugs retain their existing references.
